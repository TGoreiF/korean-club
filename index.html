Audio & microphone setup

Japanese speech is generated by your device/browser, not embedded in the file. If no Japanese voice is installed, audio may be silent or use the wrong voice.

Checking speech support…
Fix audio or microphone problems
  1. Open the file in Google Chrome, not an in-app preview or file viewer.
  2. For audio, check media volume and Android text-to-speech settings. Install Japanese voice data if offered.
  3. For microphone practice, allow microphone permission. Recognition may require an internet connection and may not work when this page is opened directly as a local file.
  4. If recognition still fails, the app cannot override a browser/device restriction. A secure hosted page is more reliable.
